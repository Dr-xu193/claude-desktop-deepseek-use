# Roadmap

## Current Phase: Public Validation Branch

This repository is currently an early public validation branch for a larger multi-model coding-agent platform developed by a 15-person team.

The current focus is to document reproducible setup and workflow patterns for:

- Claude Desktop
- DeepSeek
- MCP servers
- WSL execution
- GitHub automation
- Browser automation
- Skill-based workflow routing
