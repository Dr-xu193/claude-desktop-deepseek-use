# Experimental Multimodal Skill Pipeline

This directory contains planned notes and examples for experimental multimodal skill pipelines.

## Goal

The goal is to allow text-centric models to perform visual-understanding tasks through external perception tools, browser automation, screenshot analysis, OCR when necessary, and structured reasoning workflows.

## Important Note

This project does not claim benchmark parity with any commercial model. The focus is practical engineering: connecting tools, structuring observations, and making workflows reproducible.

## Planned Examples

- Screenshot-to-description workflow
- Browser page visual inspection workflow
- Image observation routing
- Structured visual task evaluation
- Combining external perception tools with coding-agent workflows
