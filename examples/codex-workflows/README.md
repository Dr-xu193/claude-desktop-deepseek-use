# Codex-Compatible Workflow Examples

This directory contains planned examples for Codex-assisted coding-agent workflows.

## Planned Examples

- Generate tests for an existing repository
- Refactor a small Python module
- Triage GitHub issues
- Review a pull request
- Generate release notes
- Convert natural-language tasks into executable development steps
- Use Codex with MCP-style tool routing

## Safety Notes

Examples should avoid real credentials and destructive commands. Use small test repositories and placeholder tokens.
